# HireMate HR Dashboard

This project is a full-stack HR management dashboard built with React and Node.js.

## Tech Stack
- **Frontend:** React, Tailwind CSS, Lucide React, Recharts, Motion.
- **Backend:** Node.js, Express, MongoDB.
- **Database:** MongoDB.

## Features
- Real-time dashboard stats and updates via MongoDB driver.
- Professional, high-density HR interface.
